このリポジトリを公開する前と、更新が続く間の定期的な点検で使う観点をまとめた。読者向けではなく、リポジトリを保守するための文書である。

- 対象: 追跡しているすべてのファイル（`git ls-files`）と、全履歴（すべてのブランチ・タグ・コミット）
- 実施の目安: 文書をいくつか更新したとき、pushする前、公開の直前（直前は全履歴を対象にする）
- 観点は3つ: 1節「機密情報の流出」、2節「権利侵害」、3節「リンク先が意図どおりか」。各節は「機械点検」と「目視点検」に分ける。機械点検で何も出なくても、目視点検は省かない
- 結果は4節「実施記録」に1行ずつ追記する。判断の経緯は <判断の記録の文書（例: docs/qa_log.md）> にも書く

## 1. 機密情報の流出

### 1-1. 見る観点

| 観点 | 具体例 | 主な置き場所 |
|---|---|---|
| 認証情報 | APIキー、トークン、パスワード、秘密鍵 | 全ファイル・全履歴 |
| コミットの名義 | author・committerが <公開してよい名義（例: GitHubのnoreplyアドレス）> か | `git log` のメタデータ |
| 本文の個人情報 | 実名、実メール、アカウント名（意図して載せる著作権者の表示とリポジトリのURLは対象外） | <記録系の文書>、本文 |
| PC固有の情報 | ユーザー名を含むパス、ドライブ構成、メモリ・ディスク容量などの実測値（意図して載せたもの（例: READMEの環境の情報）は対象外。ただし項目が増えていないかは見る） | <環境構築の文書> |
| PCの利用状況 | PCの具体的な用途など、個人の生活を推測させる記述、PCの扱いへの注意の言及、スペックの制約 | <企画の文書>、<Claude向けの指示の文書> |
| 組み合わせ | 1つずつは無害でも、組み合わせると推測できる情報（機種の情報と、PCの扱いへの注意の言及など） | 文書をまたいで |
| 追跡してはいけないもの | <個人メモのフォルダ>、<練習用のフォルダ>、`.env`・鍵・大きなバイナリ | `.gitignore` と `git ls-files` |
| 画像の写り込み | 画面上の個人情報・顔・書類、SVGの埋め込み画像 | <画像のフォルダ> |

### 1-2. 機械点検

<references/commands.md の 1〜5 節から、プロジェクトで使うコマンドを写す>

### 1-3. 目視点検

- <記録系の文書> に新しく足した行に、アカウント名・実メール・PC固有の情報・個人の練習環境の状態が入っていないか。
- <Claude向けの指示の文書> と <企画の文書> の、運用ルール・過去の経緯・PCの扱いへの注意の言及が、公開してよい書き方か。
- 前回の実施以降に足した画像を1枚ずつ開いて、写り込みを確かめる。

## 2. 権利侵害

### 2-1. 見る観点

| 観点 | 具体例 | 主な置き場所 |
|---|---|---|
| 公式ドキュメントの抜粋 | 帰属表示（出典・ライセンス・改変の有無）が残っているか | <該当の文書> |
| 各文書の出典の注記 | 元にしたもの・ライセンス・逐語の転載でない旨 | <対象の文書> |
| 引用の範囲 | 雛形・警告の文面・ツールの出力（型の定義の表示など）が、説明に必要な範囲に留まり、出典があるか | <該当の文書> |
| 図 | 自作の図か。第三者の図・ロゴ・埋め込み画像が混ざっていないか | <画像のフォルダ> |
| サンプルコード | 公式のチュートリアルや他のリポジトリのコードを、丸ごと転載していないか | コードブロック |
| 第三者のファイル | ライセンスが不明なファイル（PDF・フォント・画像等）が追跡されていないか | `git ls-files` |
| リポジトリのライセンス | `LICENSE` の第三者の一覧が最新か。コピーレフトの依存が加わっていないか | `LICENSE`、README |

### 2-2. 機械点検

<references/commands.md の 6 節から写す>

### 2-3. 目視点検

- 前回以降に足した節が、公式ドキュメントや記事の文章をほぼそのまま写していないか。
- 足したサンプルコードが、公式のコードと一致しすぎていないか。
- 2-1節の表の帰属表示・出典の注記が、文書の書き換えで消えていないか。

## 3. リンク先が意図どおりか

### 3-1. 見る観点

| 観点 | 具体例 |
|---|---|
| 文書間のリンク | 相対パスのリンクの先が実在するか |
| 参照の書き方 | 他の文書への参照がリンクになっているか |
| 節の参照 | 本文の「N節」などの参照が、今の見出しと合っているか |
| 外部リンクの実在 | リンク切れ・移転が無いか |
| 外部リンクの中身 | 版の固定（例: 特定のバージョンのドキュメント）、リンクの文言と中身が合っているか |

- 節を足した・繰り下げた文書と、それを参照している文書の「N節」を読み直す。
- 前回以降に足した外部リンクを開いて、文言・版・内容が本文と合っているかを確かめる。
