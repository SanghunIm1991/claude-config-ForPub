# サブエージェント一覧表示

カスタムサブエージェント定義を走査し、組み込みエージェントとあわせて一覧を提示する。名前を覚えていなくても一覧から選べるようにすることが目的。

## 手順

1. `Glob`で `.claude/agents/*.md`（プロジェクト）と `~/.claude/agents/*.md`（ユーザー共通、Windowsではホームディレクトリ配下）を検索する
2. 見つかった各ファイルを`Read`する。トークン消費を抑えるため、全文ではなく先頭15〜20行程度（frontmatterが収まる範囲）に`limit`を指定して読み、`name`・`description`を抽出する（YAML不正・`name`/`description`欠落のファイルはClaude Code自体が無視する定義なので、一覧からも除外してよい）
3. 現在のセッションで使える組み込みエージェント（会話冒頭のsystem-reminder「Available agent types for the Agent tool」に列挙されているもの）も同じ一覧に加える
4. 次の形式で表にまとめて提示する。`description`は意味を変えない範囲で1〜2文に要約してよい

   | name | 種別 | 概要 |
   |---|---|---|
   | ... | project / user / 組み込み | ... |

5. 該当するカスタムサブエージェントが0件の場合は、組み込みエージェントのみの一覧である旨を明記する
6. 一覧の最後に呼び出し方法を一言添える:「`@`+名前で直接メンションして呼び出せます（例: `@agent-name`）」

## 注意

- 一覧化のみを行う。この場でのエージェントの新規作成・編集・削除は行わない（作成・改善は`author-agent`スキルに委ねる）
